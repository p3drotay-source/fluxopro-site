# FluxoPro — demonstração (pré-lançamento)

Site estático de validação comercial. **Não há vendas, clientes, pagamentos ou dados reais**.

## Como publicar no Render

- Tipo: Static Site
- Repositório: este repositório GitHub
- Branch: main
- Build command: vazio (ou `echo static`)
- Publish directory: `.`
- Deploy automático: sim, somente se sem custos adicionais

O site está em modo demonstração, sem canal comercial definido. `config-contato.js` tem os campos vazios.
Não compartilhe e-mail/telefone pessoal sem autorização expressa.

## Antes de comercializar

Verificar nome e marca, habilitar canal comercial autorizado, definir escopo e condições comerciais, revisar privacidade/LGPD e testar fluxos reais.
Remover as tags `noindex` e alterar `robots.txt` somente no lançamento.

Nenhum token, segredo nem dado de cliente deve entrar neste repositório.
